# Studyroom-klv

Plataforma colaborativa de estudio simultáneo y gestión de tutorías académicas.

Proyecto de aula — Ingeniería de Software, grupo 1206.

## Problema

Los estudiantes de primeros semestres enfrentan dificultades para encontrar compañeros de estudio, coordinar horarios y resolver dudas de manera oportuna en asignaturas de ciencias básicas como Cálculo y Física. Esta plataforma busca reducir ese aislamiento académico conectando a estudiantes entre sí y con tutores pares, a partir de evidencia recolectada mediante una encuesta aplicada a 35 estudiantes.
